# Marionette releases

Installers for Marionette, a desktop app for making World of Warcraft machinima: write a script, act the lines on camera, and get a finished scene with lip sync, camera cuts and a rendered video.

This repository only holds the Windows installers. Download the newest `Marionette Setup x.y.z.exe` from Releases. Marionette updates itself after that.

## What you need

- Windows 10 or 11 (64-bit)
- World of Warcraft installed (Retail or Forever). Marionette reads characters, places and sounds from your own game install. Nothing from the game is included here.
- A reasonably strong PC: a scene with several characters can use a few GB of memory.

On first start Marionette finds your game folder and downloads two free tools from their own GitHub pages: [wow.export](https://github.com/Kruithne/wow.export) and [Rhubarb Lip Sync](https://github.com/DanielSWolf/rhubarb-lip-sync).

Windows may warn about an unknown publisher the first time. Choose More info, then Run anyway.
